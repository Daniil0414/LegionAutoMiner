# ⛏️ Legion Auto-Miner

Полнофункциональный скрипт-помощник для игры «Легион» (ZakvielChannel / Multidonate).

---

## 🚀 Установка в 1 клик

### Шаг 1: Установите расширение Tampermonkey
Для работы скрипта необходимо браузерное расширение **Tampermonkey**:
* [Tampermonkey для Google Chrome](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
* [Tampermonkey для Microsoft Edge](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd)
* [Tampermonkey для Mozilla Firefox](https://addons.mozilla.org/ru/firefox/addon/tampermonkey/)
* [Tampermonkey для Opera / Яндекс Браузер](https://addons.opera.com/ru/extensions/details/tampermonkey-beta/)

### Шаг 2: Установите скрипт
Нажмите на кнопку ниже или перейдите по прямой ссылке:

[![Установить скрипт в Tampermonkey](https://img.shields.io/badge/Tampermonkey-Установить%20в%201%20клик-brightgreen?style=for-the-badge&logo=tampermonkey)](https://raw.githubusercontent.com/Daniil0414/LegionAutoMiner/main/mine-bot.user.js)

👉 **Прямая ссылка:**  
https://raw.githubusercontent.com/Daniil0414/LegionAutoMiner/main/mine-bot.user.js

*(После нажатия Tampermonkey автоматически перехватит файл и откроет окно подтверждения — нажмите **«Установить»**).*

---

## 🔄 Автоматические обновления

В скрипт встроена автоматическая проверка обновлений напрямую из этого репозитория:
* **Авто-обновление:** Tampermonkey проверяет обновления в фоне и устанавливает свежие версии автоматически.
* **Ручное обновление:** В меню расширения Tampermonkey в любой момент можно нажать *«Проверить наличие обновлений скриптов»*.

## ⚙️ Основные возможности

* ⛏️ **Умная авто-шахта:** автоматическая добыча руды с настраиваемыми приоритетами ценных жил.
* 🏙️ **Фоновый и стелс-режим:** стабильная работа в свернутом окне и на фоне города без остановок.
* 🎯 **Снайпер рынка:** скоростной мониторинг аукциона и моментальный перехват выгодных лотов.
* ⚔️ **Помощник в походах:** авто-прохождение игровых событий и переправ.
* 👥 **Разведка игроков:** интерактивный поиск и быстрые действия.
