# ⛏️ Legion Auto-Miner

Приватный скрипт-помощник для игры «Легион» (ZakvielChannel / Multidonate).

---

## ⚙️ Установка

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/).
2. Откройте панель управления Tampermonkey -> **Создать новый скрипт** (+).
3. Скопируйте содержимое файла `mine-bot.user.js` и сохраните (**Ctrl+S**).

---

## ⚙️ Основные возможности

* ⛏️ **Умная авто-шахта:** автоматическая добыча руды с настраиваемыми приоритетами ценных жил.
* 🏙️ **Фоновый и стелс-режим:** стабильная работа в свернутом окне и на фоне города без остановок.
* 🎯 **Снайпер рынка:** скоростной мониторинг аукциона и моментальный перехват выгодных лотов.
* ⚔️ **Помощник в походах:** авто-прохождение игровых событий и переправ.
* 👥 **Разведка игроков:** интерактивный поиск и быстрые действия.
